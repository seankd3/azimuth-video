# Working on Azimuth Video

This adds to the agent rules every project shares. README.md is the manual.

- Changes go straight to main: commit and push, with no branches or pull requests. That is the owner's ruling for this
  tool. Code that files, moves or deletes media gets one read-only review before it lands, because a bug there costs
  footage.
- The repository is public. Code, commits and issues never name a site, company, person, place or clip. Site
  specifics live in `~/.config/azimuth-video/config.json` and in edit scripts outside the repository.
- Footage, sidecars, `people.json` and renders stay on the machine, never in git.
