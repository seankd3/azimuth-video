# Azimuth design, vendored

Generated by azimuth-design 0332aea. Do not edit these files: change azimuth-design
and run `python3 -m azimuth_design sync` there, which updates every app (apps.toml).

- `azimuth.css`: shared measures, the built-in themes as `--az-*` variables, `.az-<style>` text styles
- `azimuth-theme.js`: apply or follow a theme file at run time
- `azimuth_theme.py`: choose a theme in a Python app; `RUNTIME` is the live Omarchy theme to watch
- `themes/*.json`: the built-in theme files
- `tokens.json`: what doesn't change with the theme (type, sizes, spacing, corners, motion, media), for kits that
  read the measures at run time
- `icons.svg`, `icons.json`, `mark.svg`: the icon set (sprite; name -> path for QML) and the compass mark
- `fonts/`: Inter Tight and JetBrains Mono (SIL Open Font License)
- `qml/Azimuth/`: the Qt Quick kit (when present)
